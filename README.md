# 📊 App User Behavior Segmentation Using Unsupervised Machine Learning

## Overview

This project uses **unsupervised machine learning** to analyze app user behavior and segment 50,000 users into meaningful behavioral groups based on engagement and activity patterns.

The project uses **K-Means clustering**, supported by feature scaling, the Elbow Method, Silhouette Score, and PCA.

## Problem Statement

Applications generate large amounts of user activity data, but understanding user behavior without predefined labels is challenging.

This project identifies user segments based on similar behavioral and engagement patterns to support:

- Targeted marketing
- Churn-risk identification
- User retention
- Personalized engagement
- Product optimization
